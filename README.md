# Caminho PEI

Landing page estática em Vite, HTML, CSS e JavaScript. Os mockups são construídos com HTML/CSS/SVG; GSAP e Lenis cuidam das animações e do scroll.

## Rodar localmente

```sh
npm install
npm run dev
```

Para gerar os arquivos de produção, rode `npm run build`.

## Configuração

Edite `config.js` para trocar preços, link de checkout, e-mail, tempo de demonstração, vídeos e nomes de arquivo. `TODO` mantém um destino de checkout indisponível até receber o link correto. Substitua o espaço para depoimentos por imagens reais em `assets/depoimentos/`. A imagem Open Graph pode ser colocada em `public/assets/og.png`.

## Observações antes de publicar

- Troque os links de termos e privacidade e preencha o endereço de suporte.
- Confirme com o responsável comercial os links das ofertas por etapa e as condições de garantia.
- Insira apenas depoimentos e prints reais, com autorização para publicação.
- O texto sobre normas é informativo. Verifique a versão vigente e as orientações da rede de ensino antes de publicar.
- Respeite os dados fictícios de demonstração; não use informações de estudantes reais.
